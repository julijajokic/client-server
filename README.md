
## Running the Client-Server Application

### 1. Open the Project in NetBeans

Open the Client-Server application in NetBeans IDE

### 2. Add the Required JAR Libraries

Add the shared JAR libraries to both the `Client` and `Server` projects.

Additionally, add the MySQL Connector JAR file to the `Server` project.

### 3. Start XAMPP and the Database

Open XAMPP Control Panel and start:

- MySQL

### 4. Run the Server

In NetBeans, open the `Server` project and run the application

Make sure the server starts successfully before proceeding

### 5. Run the Client

In NetBeans, open the `Client` project and run the application

The client connects to the running server and communicates with the database through the server
